## 📋 Содержание проекта

Проект реализован в виде монолитного консольного приложения с интерактивным главным меню. Каждая лабораторная работа инкапсулирована в собственное пространство имен (`namespace`), что исключает конфликты имен классов.

| № | Тема лабораторной работы | Описание реализованного функционала |
|---|---|---|
| **1** | **Классы. Конструкторы. Деструкторы** | Создание базового класса `CMPLX` (комплексное число). Реализация конструкторов, методов `Setcompl`, `Dec`, `Div` и деструктора. |
| **2** | **Использование указателей в С++** | Разработка класса `CHAIN` для работы с цепочкой динамических переменных. Добавление/вставка элементов с использованием `calloc`/`free`. |
| **3** | **Операции new и delete** | Перевод класса `CHAIN` на `new/delete`. Создание класса `DUPARRAY` для работы с динамическими массивами и поиска дубликатов. |
| **4** | **Наследование. Виртуальные функции** | Построение иерархии классов. Виртуализация методов `Setcompl`, `Dec`, `Div` и использование полиморфизма времени исполнения. |
| **5** | **Перегрузка операторов и функций** | Перегрузка функции `Div` (деление на `float`). Перегрузка унарных (`--`) и бинарных (`/`, `+`, `-`, `*`, `==`) операторов, а также оператора `()`, `new` и `delete`. |
| **6** | **Шаблоны классов и функций** | Разработка параметризованного класса `Sequence<T>` для работы с числовыми последовательностями. Использование явной специализации и вариативных шаблонов. |
| **7** | **Потоковый ввод/вывод** | Перегрузка операторов `<<` и `>>`. Форматированный консольный и файловый ввод/вывод с использованием пользовательских манипуляторов и `std::tuple`. |
